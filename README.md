# 실시간 날씨·미세먼지 대시보드 (`26-w10-weather`)

> **MS-DOS / Windows 3.x 레트로 터미널 감성으로 즐기는 실시간 국내외 기상 및 대기질 모니터링 대시보드**  
> Open-Meteo 공개 API를 기반으로 전 세계 도시의 실시간 날씨, 24시간 시간별 기온 변화, 7일 주간 예보, 한국 환경부 기준 미세먼지(PM10/PM2.5) 수치를 직관적인 레트로 윈도우 인터페이스로 제공합니다.

---

## 📺 소개 (Overview)

본 프로젝트는 고전 **MS-DOS 및 Windows 1.x ~ 3.x의 클래식 3D 베벨 창(Bevel Window)** 디자인을 현대적인 React 19와 순수 CSS로 재해석한 기상 대시보드 웹 애플리케이션입니다.

### 🌟 핵심 기능 요약
- **주요 도시 원클릭 조회**: 서울(강서), 서울(시청), 인천, 부산, 대구, 대전, 광주, 제주 등 국내 주요 8개 도시 실시간 프리셋
- **현재 날씨 상세 카드 (`WEATHER.EXE`)**: 현재 기온, 체감 온도, 습도, 풍속 및 한국어 기상 상태 라벨
- **상세 기상 지표**: 자외선 지수(UV Index), 강수 확률(%), 일출 및 일몰 시간 표시
- **미세먼지 모니터링 (`AIR_QUALITY.COM`)**: PM10 / PM2.5 농도 수치 및 한국 환경부 기준 4단계(좋음/보통/나쁨/매우나쁨) 등급 뱃지, 도스 아스키 블록 프로그레스 바(`[██████░░░░]`)
- **24시간 시간별 기온 차트 (`24H_CHART.SYS`)**: 향후 24시간의 기온 변화를 렌더링하는 순수 경량 SVG 꺾은선 차트 (야간 달빛 아이콘 자동 보정 및 가로 스크롤 동기화)
- **7일간 주간 예보 (`WEEKLY_FORECAST.TXT`)**: 향후 1주일간의 최고/최저 기온 범위 바 및 강수 확률
- **실시간 전 세계 도시 검색 (`FIND_CITY.COM`)**: Open-Meteo Geocoding API 기반 자동완성 검색 (400ms 디바운스 적용)
- **온도 단위 원클릭 전환**: 상단 메뉴바의 `[UNIT: °C | °F]` 토글 버튼으로 섭씨와 화씨 자유 전환
- **최근 본 도시 기록 (`RECENT_CITIES.LOG`)**: `localStorage`를 활용하여 최근 검색/선택한 5개 도시 보관 및 원클릭 재방문

## 📡 데이터는 어떻게 가져오나요 (외부 API 아키텍처)

1. **Open-Meteo API의 특징**:
   - 별도의 API Secret Key 발급이나 복잡한 인증 절차가 필요 없는 무료 오픈소스 기상 데이터 API입니다.
   - 단일 엔드포인트에서 현재 날씨(`current`), 24시간 시간별 예보(`hourly`), 7일 주간 예보(`daily`), 공기질(`air-quality`) 데이터를 JSON 포맷으로 고속 제공합니다.
2. **UI와 통신 레이어의 분리 (Decoupling)**:
   - UI 컴포넌트(`src/components/*`)는 화면 렌더링과 사용자 인터랙션에만 집중하고, 모든 HTTP 통신 및 에러 처리는 [`src/api/weather.js`](./src/api/weather.js) 모듈로 단일화했습니다.
   - 이를 통해 API 엔드포인트 변경이나 파라미터 추가 시 UI 코드 수정 없이 통신 레이어만 유연하게 유지보수할 수 있습니다.
3. **디바운스(Debounce 400ms)의 필요성**:
   - 사용자가 검색창에 "London"을 입력할 때 'L', 'Lo', 'Lon'... 매 타이핑마다 API 요청을 보내면 불필요한 네트워크 트래픽이 발생하고 **429 Too Many Requests (Rate Limit 차단)**가 발생할 수 있습니다.
   - 400ms 동안 추가 입력이 없을 때만 최종 검색어로 API를 1회 호출하도록 디바운스를 적용하여 클라이언트 성능과 서버 자원을 보호했습니다.

## 🔐 보안에서 확인한 것 (사이버보안과 체크포인트)

1. **Public API vs Secret Key API 취급 방식**:
   - Open-Meteo처럼 Key가 없는 완전 공개(Public) API는 브라우저 클라이언트에서 직접 호출해도 무방합니다.
   - 하지만 유료 결제 API나 금융/개인정보를 다루는 Secret Key API는 절대 프론트엔드 코드(`React / .env`)에 포함되어서는 안 됩니다. 브라우저의 소스 보기나 네트워크 탭을 통해 즉시 탈취되어 막대한 과금 피해 및 데이터 유출로 이어집니다.
2. **BFF(Backend for Frontend) 프록시 서버의 필요성**:
   - 보안이 중요한 API는 반드시 백엔드 프록시 서버(BFF, Cloudflare Workers, Node.js API Gateway 등)를 경유해야 합니다.
   - 클라이언트는 세션 쿠키나 임시 JWT 토큰으로 내부 백엔드와 통신하고, Secret Key는 안전한 서버 환경변수에만 보관하여 외부 노출을 원천 차단합니다.
3. **Mixed Content (혼합 콘텐츠) 차단 원리**:
   - HTTPS로 암호화된 사이트에서 암호화되지 않은 HTTP 리소스를 호출하면, 공격자가 중간자 공격(MITM)을 통해 통신 내용을 도청하거나 악성 스크립트를 주입(변조)할 수 있습니다.
   - 브라우저는 사용자의 보안을 위해 이러한 혼합 콘텐츠를 사전에 강력히 차단(Blocked)하므로, 모든 외부 통신은 반드시 HTTPS 프로토콜을 사용해야 합니다.

## 🎨 커스터마이징한 부분 (나만의 개성 넘치는 대시보드)

1. **MS-DOS & Windows 3.x 레트로 터미널 테마**:
   - 고전 윈도우 3.1 특유의 네이비 타이틀바, 베벨 버튼, 모노스페이스 픽셀 폰트, CLI 프롬프트(`C:\>`), 깜빡이는 언더스코어 커서(`_`) 구현
   - 모든 날씨 및 지표 아이콘을 **16픽셀(`size={16}`)**로 정밀 규격화
2. **옵션 A (기상 상태 기반 동적 레트로 테마)**:
   - 맑은 낮: 클래식 Windows 3.1 Teal 데스크톱 (`#008080`)
   - 야간: 매트릭스 느낌의 도스 그린 CRT 터미널
   - 비/눈/뇌우: 감성적인 레트로 앰버(Amber) CRT 터미널로 자동 전환
3. **옵션 B (최근 본 도시 로컬스토리지 저장)**:
   - 검색하거나 선택한 도시를 `localStorage`에 자동 누적하고 상단에 `RECENT_CITIES.LOG` 칩으로 표시하여 원클릭 빠른 이동 및 삭제 지원
4. **옵션 C (상세 기상 데이터 확장)**:
   - 자외선 지수(UV Index), 강수 확률(%), 일출/일몰 시간 실시간 표시
5. **옵션 D (섭씨/화씨 온도 단위 변환 토글)**:
   - 상단 메뉴바의 `[UNIT: °C | °F]` 토글 버튼으로 24시간 차트 및 주간 예보까지 전면 단위 변환 지원
