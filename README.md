# 실시간 스마트 날씨·미세먼지 대시보드 (`26-w10-weather`)

전 세계 실시간 기상 데이터와 한국 환경부 기준 대기질 지수를 실시간으로 시각화하는 인터랙티브 스마트 기상 대시보드 웹 애플리케이션입니다.  
구글의 차세대 AI 코딩 IDE인 **Antigravity**를 활용하여 계획 수립(Implementation Plan)부터 자율 검증(Walkthrough)까지 체계적으로 구축되었습니다.

---

## 🌤️ 주요 기능 소개

- **🌙 기본 나이트(다크) 모드 & 원클릭 모드 토글**:
  - 첫 방문 시 눈의 피로를 줄여주는 나이트 모드가 기본 적용되며, 헤더의 `Sun` / `Moon` 버튼을 통해 라이트 모드와 나이트 모드를 자유롭게 전환할 수 있습니다. (`localStorage` 자동 연동)
- **🎨 기상 상태 연동 동적 SVG 배경 그래픽 & 그라데이션**:
  - 현재 날씨(맑음, 비/소나기, 눈, 흐림, 뇌우, 밤)에 맞춰 은은한 별무리, 사선 빗줄기, 눈꽃송이 등 맞춤형 인라인 SVG 그래픽 패턴과 무드 그라데이션이 자동으로 부드럽게 전환됩니다.
- **🪟 글래스모피즘 (Glassmorphism) 카드 UI**:
  - `backdrop-filter: blur(16px)`와 섬세한 반투명 카드 레이아웃을 통해 배경 그래픽이 은은하게 투과되는 모던 비주얼을 제공합니다.
- **⚡ 실시간 기상 및 환경부 대기질 지표**:
  - 기온, 체감온도, 상대습도, 풍속, WMO 날씨 코드 매핑 Lucide 아이콘
  - 미세먼지(PM10) & 초미세먼지(PM2.5) 농도 및 환경부 4단계(좋음/보통/나쁨/매우 나쁨) 컬러 뱃지 및 프로그레스 바
- **📈 오늘 24시간 시간별 기온 추이 SVG 차트 (`HourlyChart`)**:
  - 외부 무거운 라이브러리 없이 순수 SVG `<polyline>` 및 `<polygon>`으로 가볍고 빠른 미니 꺾은선/영역 차트 구현 (현재 시각 하이라이트 및 가로 스크롤 최적화)
- **📅 향후 7일간 주간 일기예보 (`WeeklyForecast`)**:
  - 요일별 최고/최저 기온 범위 바, 강수 확률(%), 날씨 아이콘 제공
- **🔍 400ms 디바운스 실시간 도시 검색 (`CitySearch`)**:
  - 빠른 타이핑 시 불필요한 요청을 차단하고 `429 Too Many Requests`를 방어하는 디바운스 검색창 및 드롭다운
- **📌 최근 조회 도시 저장 (`RecentCities`)**:
  - `localStorage` 기반으로 최근 조회한 도시를 최대 5개 자동 보관, 상단 칩을 통한 원클릭 재방문 및 삭제 지원
- **🌡️ 섭씨(°C) / 화씨(°F) 원클릭 단위 변환 스위치**:
  - 현재 기온, 24시간 차트, 7일간 예보의 기온 수치를 실시간 일괄 변환 (`°F = °C * 1.8 + 32`)

- **자율 검증 및 Walkthrough**:
  - 컴포넌트 모듈화 및 기능 구현 직후 `npm run build`와 로컬 개발 서버(Vite) 상태를 에이전트가 자체적으로 점검하여 번들링 오류와 런타임 결함을 즉시 해결했습니다.
- **프로젝트 커밋 규칙 위임 (`GEMINI.md` / Rules 시스템)**:
  - 프로젝트 루트의 커밋 규칙에 따라 한국어 작성, 50자 요약 제목, 불릿 포인트 상세 본문, `Co-authored-by` 모델 서명 규격을 에이전트가 완벽히 준수하여 고품질의 Git 히스토리를 자동으로 생성했습니다.

## 📡 데이터는 어떻게 가져오나요 (외부 API 아키텍처)

- **Open-Meteo Public API 활용**:
  - API 키 발급이나 복잡한 인증 절차 없이, 표준 HTTPS 프로토콜을 통해 기상청/유럽중기예보센터 데이터를 제공하는 공개 API 엔드포인트를 호출합니다.
- **관심사 분리 (Decoupling Architecture)**:
  - React UI 컴포넌트(`src/components/*`)와 외부 API 통신 레이어([`src/api/weather.js`](./src/api/weather.js))를 엄격히 분리하였습니다. 네트워크 호출 오류 처리(`try/catch`), WMO 코드 변환, 환경부 기준 등급 산출 로직을 모듈화하여 코드 재사용성과 유지보수성을 극대화했습니다.
- **디바운스(Debounce, 400ms) 적용**:
  - 도시 검색창(`CitySearch.jsx`)에서 사용자가 타이핑할 때 매 키 입력마다 API를 요청하면 서버에 불필요한 과부하가 발생하고 `429 Too Many Requests`로 IP가 차단될 수 있습니다. `setTimeout` 클린업을 활용한 **400ms 디바운스**를 적용해 타이핑이 멈춘 시점에만 1회 호출하도록 네트워크 트래픽을 최적화했습니다.

## 🛡️ 보안에서 확인한 것 (사이버보안과 체크포인트)

1. **공개 API(Public) vs 비밀 API(Secret/Private) 취급 차이**:
   - Open-Meteo는 비밀 키가 없는 완전 공개 API이므로 프론트엔드(React)에서 직접 호출해도 안전합니다.
   - 하지만 유료 과금 API, 결제 모듈, 사내 회원정보 조회 API처럼 **비밀 키(Secret Key)**가 필요한 서비스는 **절대로 클라이언트(브라우저) 코드에 키를 포함해서는 안 됩니다**. 브라우저 개발자 도구의 Network 탭이나 번들링된 JS 파일(`dist/*.js`)을 통해 100% 탈취당할 수 있기 때문입니다.
2. **백엔드 프록시 (BFF, Backend For Frontend) 필요성**:
   - 비밀 키가 필요한 환경에서는 프론트엔드가 자체 백엔드 서버(Node.js, Python, Serverless 함수 등)에 요청하고, 백엔드 서버가 환경변수(`.env`)에 숨겨진 Secret Key로 외부 API를 대리 호출한 뒤 결과만 프론트엔드에 전달하는 프록시 아키텍처를 반드시 구축해야 합니다.
3. **CORS와 Mixed Content (HTTPS 보안 방어)**:
   - 프로덕션 배포 사이트(`https://`)에서 암호화되지 않은 안전하지 않은 `http://` 엔드포인트를 호출하면, 중간자 공격(MITM) 및 패킷 도청/변조 위협을 방지하기 위해 브라우저 보안 정책이 통신을 강제로 차단(Mixed Content Block)합니다. 따라서 모든 외부 자원은 검증된 HTTPS 프로토콜로만 통신해야 합니다.

## 🎨 커스터마이징한 부분 요약

실습 6단계 커스터마이징 챌린지에서 **옵션 A**, **옵션 B**, **옵션 D**를 결합하여 완성도를 높였습니다:

1. **옵션 A — 기상 및 주야간(`is_day`) 연동 동적 비주얼 테마 & 나이트/라이트 모드**:
   - **기본 나이트(다크) 모드 탑재**: 첫 방문 시 눈이 편안한 나이트 모드가 기본 적용되며, 헤더의 토글 버튼으로 라이트/나이트 모드를 자유롭게 전환(`localStorage` 자동 저장)할 수 있습니다.
   - **날씨별 동적 배경 그래픽**: 야간(은은한 별무리 SVG 패턴 & 딥 인디고), 맑음(태양 래디얼 빔 & 스카이블루), 비/소나기(사선 빗줄기 패턴), 눈(흩날리는 눈꽃송이 패턴), 흐림/안개(미스트 웨이브 패턴), 뇌우(일렉트릭 펄스) 등 6가지 날씨 조건에 맞춘 배경 일러스트 패턴 및 색상 그라데이션이 자동 반영됩니다.
   - **글래스모피즘(Glassmorphism)**: 대시보드 카드에 블러 효과(`backdrop-filter: blur(16px)`)와 반투명 배경을 적용하여 감성적인 배경 그래픽이 은은하게 비치도록 설계했습니다.
2. **옵션 B — 최근 조회 도시 `localStorage` 저장 및 원클릭 재방문**:
   - 사용자가 검색하거나 클릭한 도시 정보를 브라우저 `localStorage`에 자동 보관(최대 5개, 중복 제거)하여 상단에 알약 칩(`RecentCities.jsx`)으로 표시합니다. 클릭 한 번으로 이전 조회 도시로 이동하거나 개별 삭제/전체 비우기가 가능합니다.
3. **옵션 D — 섭씨(°C) / 화씨(°F) 원클릭 단위 변환 스위치**:
   - 상단 헤더에 단위 토글 버튼을 배치하여, 현재 기온 및 체감온도뿐만 아니라 24시간 시간별 기온 차트와 7일간 주간 예보의 기온 수치까지 일괄 실시간 변환(`°F = °C * 1.8 + 32`)되도록 구현했습니다.
