# 실시간 날씨·미세먼지 대시보드 (`26-w10-weather`)

> **한국폴리텍대학 강서캠퍼스 사이버보안과 웹콘텐츠 제작 10주차 실습 프로젝트**  
> Google Antigravity IDE의 에이전틱 워크플로우를 활용하여 구축한 실시간 글로벌 기상 및 공기질 모니터링 웹 대시보드입니다.

---

## 🌤️ 소개

본 프로젝트는 React 19와 Vite 기반으로 제작된 반응형 날씨 및 미세먼지 모니터링 웹 애플리케이션입니다.  
글로벌 기상 관측 공개 API인 **Open-Meteo**를 연동하여 전 세계 주요 도시의 실시간 기상 데이터와 한국 환경부 기준의 대기질(미세먼지) 정보를 직관적이고 미려한 UI로 제공합니다.

### 🌟 주요 기능
1. **국내 주요 8개 도시 퀵 셀렉터**: 서울(강서), 서울(시청), 인천, 부산, 대구, 대전, 광주, 제주의 기상 정보를 원클릭으로 즉시 조회
2. **실시간 현재 날씨 카드 (`CurrentWeather`)**: 현재 기온(°C), 체감 온도, 습도, 풍속, 강수량 및 WMO 코드 기반 한국어 상태 라벨과 `lucide-react` 동적 아이콘 매핑
3. **환경부 기준 미세먼지 카드 (`AirQualityCard`)**: PM10, PM2.5, 유럽 AQI 지수 표시 및 환경부 4단계(좋음/보통/나쁨/매우나쁨) 컬러 뱃지 & 게이지 바 제공
4. **24시간 시간별 기온 SVG 차트 (`HourlyChart`)**: 외부 차트 라이브러리 없이 인라인 SVG와 그라데이션 영역 채우기로 구현한 24시간 미니 꺾은선 기온 변화 차트
5. **7일간 주간 일기예보 (`WeeklyForecast`)**: 요일별 날씨 아이콘, 강수 확률(%), 주간 최저/최고 기온 막대 게이지 시각화
6. **글로벌 도시 검색창 (`CitySearch`)**: Geocoding API를 연동하여 전 세계 도시 검색 지원 (API 남용 및 429 차단 방지용 **400ms 디바운스** 적용)
7. **날씨·낮밤 연동 동적 테마 (커스터마이징)**: 날씨 상태와 낮/밤(`is_day`)에 따라 대시보드 배경 그라데이션 및 글래스모피즘(Glassmorphism) 테마 자동 전환

## 📡 데이터는 어떻게 가져오나요 (외부 API 아키텍처)

- **Open-Meteo 기상 및 미세먼지 API의 특징**:  
  - 별도의 회원가입이나 Secret API Key 발급 절차가 전혀 필요 없는 완전 공개(Public) 기상 데이터 서비스입니다.
  - 전 세계 수치예보 모델(WMO 기상 코드)을 기반으로 현재 날씨, 시간별 예보, 7일 주간 예보, 공기질 데이터를 고성능 HTTPS 엔드포인트로 무료 제공합니다.
- **UI 컴포넌트(`App.jsx`)와 API 통신 로직(`src/api/weather.js`) 분리 이유 (Decoupling)**:  
  - **관심사의 분리(Separation of Concerns)** 원칙을 적용하여 화면을 그리는 렌더링 계층과 네트워크 통신 계층을 엄격히 격리했습니다.
  - 데이터 통신 함수(`fetchWeatherData`, `fetchAirQualityData`, `searchCities`)가 전용 모듈로 캡슐화되어 있어, 향후 기상청 공공데이터 포털 등 타 API로 공급자를 변경하거나 테스트용 목(Mock) 데이터로 교체할 때도 UI 코드 수정 없이 통신 계층만 독립적으로 유지보수할 수 있습니다.
- **도시 검색 시 디바운스(Debounce, 400ms)의 필요성**:  
  - 사용자가 검색창에 "London"을 입력할 때 `L`, `o`, `n`, `d`, `o`, `n` 한 글자를 누를 때마다 즉시 API를 호출하면 단 1초 만에 6회 이상의 불필요한 네트워크 요청이 쏟아집니다.
  - 이는 클라이언트 측 네트워크 낭비일 뿐 아니라, 서버 입장에서 DoS(서비스 거부) 형태의 트래픽 폭주로 간주되어 **HTTP 429 Too Many Requests** 오류와 함께 사용자 IP가 일시 차단될 수 있습니다.
  - **400ms 디바운스**를 적용하여 사용자의 연속된 타이핑이 멈춘 뒤 400ms 동안 추가 입력이 없을 때 비로소 단 1회의 완성된 검색 요청을 전송하도록 최적화했습니다.

## 🛡️ 보안에서 확인한 것 (사이버보안과 체크포인트)

- **공개 API(Public API) vs 비밀 API(Secret API)의 보안 취급 차이**:  
  - Open-Meteo와 같은 Public API는 식별용 키가 없으므로 브라우저 클라이언트에서 직접 호출해도 안전합니다.
  - 반면 결제 모듈(토스페이먼츠, 스트라이프 등), 생성형 AI(Gemini, OpenAI), 사내 고객 데이터베이스 등 과금이나 권한이 결부된 유료 API는 **비밀 키(Secret Key)**를 기반으로 인증합니다. 이러한 키는 결코 클라이언트 환경에 노출되어서는 안 됩니다.
- **프론트엔드 직접 호출의 위험성과 백엔드 프록시(BFF)의 필수성**:  
  - 만약 React 프론트엔드 소스코드나 `.env`에 Secret Key를 넣고 브라우저에서 직접 외부 API를 호출하면, 사용자가 브라우저 개발자 도구(F12)의 **Network 탭**을 열어보거나 빌드된 자바스크립트 번들 파일을 역공학(DevTools Sources 확인)하는 것만으로 비밀 키가 100% 탈취당합니다.
  - 키 탈취는 즉각 거액의 API 사용료 과금 공격이나 민감 데이터 유출 사고로 직결됩니다.
  - 이를 방어하기 위해 반드시 클라이언트와 외부 API 사이에 **BFF(Backend For Frontend) 프록시 서버**를 두어야 합니다. 클라이언트는 자체 백엔드 엔드포인트만 호출하고, Secret Key는 안전하게 격리된 백엔드 서버 환경변수에 숨긴 채 서버 대 서버(Server-to-Server)로 외부 API와 통신해야 합니다.
- **HTTPS와 혼합 콘텐츠(Mixed Content) 방어**:  
  - 배포된 사이트가 암호화된 `https://` 프로토콜을 사용할 때, 내부 자바스크립트 코드가 평문인 `http://` 엔드포인트를 호출하면 웹 브라우저의 보안 정책(SOP/CSP)에 의해 통신이 강제로 차단됩니다. 이를 **Mixed Content(혼합 콘텐츠)** 차단이라고 합니다.
  - 암호화되지 않은 HTTP 패킷은 공용 Wi-Fi나 통신망 경로에서 공격자에 의한 패킷 스니핑(도청) 및 중간자 공격(MITM, 중간 변조)에 취약하기 때문에, 브라우저는 보안 연결의 무결성을 지키기 위해 비보안 요청을 원천 차단합니다. 본 프로젝트의 모든 API 엔드포인트는 `https://` 암호화 통신을 준수합니다.

## 🎨 커스터마이징한 부분

### [옵션 A: 날씨 및 낮/밤(`is_day`) 연동 동적 비주얼 테마 엔진]
기본 요구사항을 넘어 사용자의 몰입감을 극대화하기 위해 기상 조건에 따라 대시보드 전체의 룩앤필이 실시간으로 변하는 **동적 비주얼 테마 엔진**을 추가 구현했습니다:

1. **상태 기반 테마 판정 로직 (`getThemeInfo`)**:
   - `is_day === 0`: 깊은 딥 네이비 & 인디고 그라데이션의 **밤하늘 테마(`theme-night`)** 또는 **밤 비 감성 테마(`theme-night-rain`)** 적용
   - `is_day === 1`:
     - 맑음(WMO 0, 1): 따스한 에메랄드 & 앰버 골드 햇살의 **맑음 테마(`theme-sunny`)**
     - 흐림(WMO 2, 3, 45, 48): 차분하고 부드러운 소프트 슬레이트의 **구름 테마(`theme-cloudy`)**
     - 비/소나기(WMO 51~65, 80~95): 청량하고 촉촉한 블루 그라데이션의 **비 테마(`theme-rainy`)**
     - 눈(WMO 71~77): 맑은 화이트 & 아이스 블루의 **눈 테마(`theme-snowy`)**
2. **글래스모피즘(Glassmorphism) 및 텍스트 고대비 처리**:
   - 주간 테마에서는 밝은 반투명 카드와 미세한 드롭 섀도우를, 야간 테마에서는 다크 반투명 글래스(`backdrop-filter: blur(14px)`)와 고대비 화이트 텍스트를 적용하여 어떤 테마에서도 완벽한 가독성을 보장했습니다.
3. **상단 실시간 테마 상태 뱃지**:
   - 상단 대시보드 타이틀 옆에 현재 작동 중인 테마 상태(`☀️ 낮 · 화창한 햇살 테마`, `🌙 밤 · 차분한 밤하늘 테마` 등)를 시각적 뱃지로 표시하여 현재 관측소의 상태를 한눈에 파악할 수 있도록 했습니다.
