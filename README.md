# 실시간 날씨·미세먼지 대시보드 (`26-w10-weather`)

Google Antigravity IDE와 Open-Meteo 공개 기상 API를 연동하여 제작한 실시간 날씨·미세먼지 스마트 대시보드(SkyPulse Weather)입니다.

---

## 소개

전 세계 주요 도시의 실시간 기상 상태와 대기질(미세먼지)을 한눈에 파악할 수 있는 모던 카드형 대시보드 웹 애플리케이션입니다.

- **8대 주요 도시 프리셋**: 서울(강서), 서울(시청), 인천, 부산, 대구, 대전, 광주, 제주를 클릭 한 번으로 빠르게 조회
- **현재 기온 및 날씨 상세**: 기온, 체감온도, 습도, 풍속, 강수량 및 WMO 표준 한글 기상 상태 라벨
- **환경부 기준 미세먼지 카드**: PM10(미세먼지)과 PM2.5(초미세먼지) 수치 및 4단계('좋음/보통/나쁨/매우나쁨') 컬러 뱃지
- **24시간 시간별 기온 차트**: 오늘 하루 기온 추이를 보여주는 반응형 SVG 미니 꺾은선 차트
- **향후 7일간 주간 예보**: 요일별 날씨 상태, 아이콘, 강수 확률(%), 최고/최저 기온 범위 바(Bar)
- **400ms 디바운스 도시 검색**: 전 세계 도시명을 검색하고 자동완성 드롭다운을 통해 바로 조회

---

## 어떻게 만들었나요 (Antigravity IDE 경험)

- **Copilot과의 차이점**: 이전 주차에서 사용했던 GitHub Copilot은 한 줄씩 인라인 코드를 추천하는 수동적인 방식이었던 반면, Antigravity IDE는 전체 프로젝트 구조와 요구사항을 깊이 이해하고 먼저 체계적인 **구현 계획(Implementation Plan)**을 수립하여 승인을 받는 점이 매우 혁신적이었습니다.
- **Implementation Plan 소감**: 코드를 무작정 생성하기 전에 아키텍처 다이어그램과 데이터 흐름, 컴포넌트 분리 계획을 시각적으로 검토할 수 있어서 설계 결함을 사전에 예방할 수 있었습니다.
- **Walkthrough 검증 리포트**: 구현이 완료된 후 빌드 결과, 린트 검사(oxlint), 컴포넌트별 기능 검증을 담은 리포트를 제공받아 개발 신뢰도를 크게 높일 수 있었습니다.

## 데이터는 어떻게 가져오나요 (외부 API 아키텍처)

- **Open-Meteo API의 특징**: 복잡한 회원가입이나 Secret API Key 발급 없이, HTTPS 프로토콜을 통해 전 세계 기상 및 대기질 데이터를 무료로 제공하는 완전 공개(Public) API입니다.
- **UI 컴포넌트와 API 통신 로직 분리(`src/api/weather.js`)**: UI 표현 계층(`App.jsx`, 컴포넌트들)과 데이터 페칭 로직(`weather.js`)을 분리(Decoupling)함으로써, 향후 기상 데이터 공급자가 변경되더라도 UI 코드 수정 없이 통신 계층만 손쉽게 교체할 수 있는 확장성을 확보했습니다.
- **도시 검색 디바운스(Debounce 400ms)의 필요성**: 검색창 입력 시 한 글자 타이핑마다 API를 호출하면 순간적으로 수십 건의 불필요한 요청이 발생합니다. 이는 서버에 DoS 형태의 부하를 주며 `429 Too Many Requests`로 IP가 차단될 수 있으므로, 입력이 멈춘 후 400ms 이후에 1회만 호출되도록 디바운스 처리를 적용했습니다.

## 보안에서 확인한 것 (사이버보안과 체크포인트)

- **공개 API vs 비밀 API(Secret Key)**: Open-Meteo처럼 읽기 전용 공개 데이터는 프론트엔드 직접 호출이 가능하지만, 결제 모듈이나 중요 사용자 정보를 다루는 유료/보안 API는 비밀 키(`Secret Key`)가 프론트엔드에 노출되면 심각한 금전 피해와 데이터 유출이 일어납니다.
- **백엔드 프록시(BFF, Backend For Frontend)의 필수성**: 비밀 키를 안전하게 보호하기 위해 클라이언트는 자체 백엔드 서버를 통해서만 통신하고, 백엔드 서버가 환경변수(`.env`)에 숨겨둔 Secret Key로 외부 API를 호출하는 프록시 아키텍처를 구축해야 합니다.
- **HTTPS 혼합 콘텐츠(Mixed Content) 방어**: HTTPS로 암호화된 안전한 배포 사이트에서 보안이 취약한 `http://` 엔드포인트를 호출할 경우 브라우저 보안 정책에 의해 통신이 강제 차단됩니다. 본 프로젝트는 모든 API 통신을 엄격한 HTTPS로 일원화했습니다.

## 커스터마이징한 부분

1. **옵션 A (동적 비주얼 테마)**: 날씨 상태(맑음, 비, 눈, 안개, 흐림) 및 주/야간(`is_day`) 파라미터에 따라 대시보드 전체 배경 그라데이션 및 카드 테마가 동적으로 변경되도록 구현했습니다.
2. **옵션 B (최근 본 도시 / 즐겨찾기)**: 사용자가 검색하거나 선택한 도시를 브라우저 `localStorage`에 자동 저장하여, 상단에 '최근 본 도시' 뱃지로 띄우고 원클릭으로 다시 볼 수 있도록 하였습니다.
3. **옵션 D (온도 단위 변환 토글)**: 상단 헤더의 토글 버튼을 통해 섭씨(°C)와 화씨(°F)를 실시간으로 전환할 수 있는 단위 변환 기능을 탑재했습니다.
